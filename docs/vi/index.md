# P2PDigital Data Marts

**P2PDigital Data Marts** giúp đội ngũ dữ liệu kết nối nguồn, xây dựng kho dữ liệu phân tích (Data Mart), kiểm soát logic và phân phối báo cáo tới Google Sheets, Looker Studio, email hoặc các điểm đến khác.

- [Bắt đầu nhanh](getting-started/quick-start.md)
- [Khái niệm cốt lõi](getting-started/core-concepts.md)
- [Tạo và quản lý Data Mart](getting-started/setup-guide/data-mart.md)
- [Thiết lập Kho lưu trữ](getting-started/setup-guide/storage.md)
- [Thiết lập Điểm đến](getting-started/setup-guide/destination.md)
- [Phân tích chuyên sâu](getting-started/setup-guide/insights.md)

Các tên API, endpoint, lệnh CLI, SQL, JSON và package `@owox/*` được giữ nguyên để đảm bảo tương thích kỹ thuật.

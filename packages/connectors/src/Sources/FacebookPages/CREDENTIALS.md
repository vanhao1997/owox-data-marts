# Facebook Fanpage credentials

The connector supports shared Facebook Login OAuth or manual Facebook Ads-style credentials. OAuth stores the exchanged long-lived user token in the tenant-scoped OWOX connector credential store.

Configure these backend/web environment variables:

```text
OAUTH_FACEBOOK_PAGES_APP_ID=<Facebook App ID>
OAUTH_FACEBOOK_PAGES_APP_SECRET=<Facebook App Secret>
OAUTH_FACEBOOK_PAGES_SCOPE=pages_show_list,read_insights,pages_read_engagement,instagram_basic,instagram_manage_insights
```

The Facebook App must request the listed permissions and may require Meta App Review. A user must have access to the selected Page and the `ANALYZE` task. The Page access token is generated by Meta from the stored user token at import time; do not paste or store a Page access token in a Data Mart configuration.

Manual fields: `Access Token`, `App ID`, `App Secret`, and comma/newline-separated `Page IDs`. Credentials remain server-side and are never returned to the browser.
